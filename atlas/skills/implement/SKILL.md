# Implement Feature - 功能实现工作流

## 何时使用

- "实现用户认证功能"
- "添加数据导出功能"
- "开发实时通知系统"

## 工作流程

### 1. 需求理解
明确功能目标、涉及模块、特殊要求

### 2. 分析阶段
使用 Glob/Read/Grep/Serena 了解现有代码结构

### 3. 规划阶段
```
Task(subagent_type="Plan")
prompt: 实现[功能], 上下文: [分析结果]
→ 返回实现计划和并行策略
```

### 4. 执行阶段
根据计划调用 atlas-executor:
- **并行**: 一次性发起所有可并行 executor
- **串行**: 按顺序执行有依赖任务
- **混合**: 分阶段执行

### 5. 验证总结
生成实现报告：成功/失败统计、文件变更、注意事项

## 核心原则

### ✅ 必须做到
- 按流程: 分析→规划→执行
- 主线程编排，调用 agents
- 尽可能并行执行

### ❌ 禁止操作
- 不跳过规划
- 不让 agents 互调
- 不串行执行可并行任务

---

**记住**: 分析→规划→执行，确保高质量实现。
