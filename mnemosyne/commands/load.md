# /mnemosyne:load - 加载上下文

用户输入: $ARGUMENTS

---

## 第一步：获取上下文列表

**读取索引文件**: `.claude/mnemosyne/index.json`

**如果用户指定了 ID**：直接加载对应上下文
**如果用户指定了 --latest**：加载最近一次保存的上下文
**否则**：显示列表供用户选择

---

## 第二步：显示选择列表

**使用 AskUserQuestion 让用户选择：**

```
最近保存的上下文：

1. [20241225-103000] 实现用户认证功能
   标签: feature, auth, React
   时间: 2024-12-25 10:30

2. [20241224-150000] 修复登录页面 Bug
   标签: bugfix, auth
   时间: 2024-12-24 15:00

3. [20241223-090000] 项目初始化配置
   标签: config, setup
   时间: 2024-12-23 09:00

请选择要加载的上下文：
```

---

## 第三步：加载并展示

**读取上下文文件**: `.claude/mnemosyne/<folder>/context.md`

**向用户展示关键信息：**

```markdown
## 📥 已加载上下文

**标题**: 实现用户认证功能
**项目**: my-app
**保存时间**: 2024-12-25 10:30

---

### 🎯 需求摘要
为应用添加 JWT 认证功能...

### ✅ 当前进度
- [x] JWT 工具函数
- [x] 登录页面
- [ ] 注册页面（50%）

### 🚀 续作指引
从注册页面的表单验证开始...

---

上下文已加载完成，可以继续之前的工作了！
```

---

## 输出格式

加载成功后，Claude 应该：
1. 理解项目背景和当前状态
2. 知道之前做了什么决策
3. 清楚下一步应该做什么
4. 了解相关的文件和代码
