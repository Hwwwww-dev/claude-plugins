# /mnemosyne:save - 保存上下文

用户输入: $ARGUMENTS

> **核心原则**：像写工作日志一样记录会话；不瞎猜，缺失信息写“未提及/无”。

---

## 第一步：用户确认

1) **快速预览**（不做深度提取）：
- 一句话会话摘要（做了什么 + 当前状态）
- 粗略规模：对话轮次、工具调用、文件变更数量
- 主要涉及的模块/路径

2) **AskUserQuestion 确认**：标题/标签/是否保存；若用户取消则直接结束。

```markdown
## 📝 保存上下文确认

**会话摘要**: [快速识别的核心内容]
**预估规模**: 约 [X] 轮对话, [Y] 个文件变更

请确认保存信息：
- 标题: [自动建议] / 用户自定义
- 标签: [自动建议] / 用户自定义
- 操作: 确认保存 / 修改信息 / 取消
```

---

## 第二步：创建记忆目录

仅在用户确认后执行：

```
.claude/mnemosyne/
├── index.json
└── <YYYYMMDD-HHMMSS>-<标题>/
    ├── context.md
    ├── snippets/      # 可选：长代码片段
    └── attachments/   # 可选：日志/截图等
```

- 若 `index.json` 不存在则创建；随后追加一条新记录元数据（字段按项目约定）。
- 路径统一为项目相对路径；能写到 `file:line` 就写。

---

## 第三步：智能信息提取

总规则：
- 只记录**事实/决定/结果**；推断必须显式标注为“推断”。
- “代码变更”只写摘要与定位，不贴长代码；关键片段放 §11（必要时落盘 `snippets/`）。
- 缺失项写“未提及/无”，不要直接省略章节。

### 3.1 起点：用户意图 (Intent)

- 从第一条用户消息提取：动作、目标、约束（性能/兼容/禁止改动等）
- 写入：context.md §1

示例：
```
用户: "给登录页加记住密码，用 localStorage，不用 cookie"
→ 目标: 记住密码；约束: localStorage；禁止: cookie
```

### 3.2 过程：关键决策 (Decisions)

- 记录每次选择：决策点 / 选择 / 理由（用户同意/拒绝/改口都算）
- 写入：§2（表格）

### 3.3 产出：代码变更 (Changes)

- 汇总：新建/修改/删除文件、依赖变更、关键命令（build/test/migrate 等）
- 写入：§3

建议格式（示例）：
```
新建: src/hooks/useRememberMe.ts, src/utils/storage.ts
修改: src/pages/Login.tsx, src/types/auth.ts
删除: 无
依赖: 无
命令: npm test, npm run dev
```

### 3.4 状态：任务进度 (Progress)

- 基于需求点完成情况估算 completion（完成/进行中/待开始）
- 写入：§4

### 3.5 障碍：问题与解决 (Issues)

- 记录报错/阻塞点/绕过方案/是否遗留
- 写入：§5（表格）

### 3.6 环境：技术上下文 (Tech Context)

- 语言/框架/包管理/构建工具/测试工具/关键配置
- 写入：§6

### 3.7 地图：文件关联 (File Map)

- 核心文件（直接改动）+ 关联文件（被引用/影响）+ 依赖链（简图）
- 写入：§7

### 3.8 路标：续作指引 (Continuation)

- 当前状态、下一步行动（可执行）、快速恢复（先读哪些文件/跑哪些命令/从哪继续）
- 写入：§8

### 3.9 会话统计 (Session Stats)

- 对话规模 + 工具统计 + 时长（粗略即可）
- 写入：§9

### 3.10 代码质量分析 (Code Quality)

- 变更规模（+/-/净增）+ lint/type/test/coverage（有则写，无则标注未运行）
- 写入：§10

### 3.11 关键代码片段 (Code Snippets)

- 仅保留最关键 3–5 段：函数签名 + 关键逻辑；标注文件/行号/用途
- 写入：§11（必要时落盘 `snippets/`）

### 3.12 时间线视图 (Timeline)

- 5–10 个关键节点（需求/决策/实现/修复/测试）
- 写入：§12

### 3.13 学习笔记 (Learning Notes)

- 新知识点/踩坑/最佳实践/参考来源
- 写入：§13

### 3.14 关联资源 (Related Resources)

- 外部链接 + 关键词（便于后续 search）
- 写入：§14

### 3.15 影响分析 (Impact Analysis)

- 直接/间接影响 + 风险等级 + 测试建议（回归范围）
- 写入：§15

---

## 第四步：输出确认（必须执行）

写入前自检（缺失项写“未提及/无”，不要省略章节）：
- [ ] `context.md` 含 frontmatter + §1–§15
- [ ] 变更文件/命令/依赖信息齐全（尽量 `file:line`）
- [ ] 续作指引可执行（含文件/命令/下一步）
- [ ] `index.json` 已追加本次记录元数据
- [ ] 目录结构已创建（含可选目录如需）

---

## 第五步：生成预览并保存

先输出预览摘要，再写入文件：

```markdown
## 📋 上下文提取完成

**标题**: <title>
**标签**: <tags>
**摘要**: <一句话摘要>
**完成度**: <X>%
**涉及文件**: <N> 个
```

然后：
1. 写入 `.claude/mnemosyne/<folder>/context.md`
2. 更新 `.claude/mnemosyne/index.json`
