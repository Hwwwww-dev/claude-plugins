# /mnemosyne:clean - 清理上下文

用户输入: $ARGUMENTS

---

## 清理规则

1. **按时间清理**: `--days N` 删除 N 天前的记录（默认 90 天）
2. **预览模式**: `--dry-run` 只显示将被删除的记录，不实际删除

---

## 执行流程

1. **扫描记录**：找出符合清理条件的上下文
2. **显示预览**：列出将被清理的记录
3. **确认清理**：使用 AskUserQuestion 确认
4. **执行清理**：删除文件夹和更新索引

---

## 预览输出

```markdown
## 清理预览

将清理 90 天前的上下文记录：

| # | ID | 标题 | 时间 |
|---|-----|------|------|
| 1 | 20240901-100000 | 旧项目配置 | 2024-09-01 |
| 2 | 20240815-140000 | 测试功能 | 2024-08-15 |
| 3 | 20240801-090000 | 初始化 | 2024-08-01 |

共 3 个上下文将被清理，释放约 0.5 MB 空间

确认清理吗？
```

---

## 确认流程

**使用 AskUserQuestion**:
- 选项 1: 确认清理
- 选项 2: 取消
- 选项 3: 调整天数

---

## 输出格式

清理成功：
```
清理完成

已删除 3 个过期上下文
释放空间: 0.5 MB
```

无需清理：
```
无需清理

没有找到符合条件的过期上下文
```

Dry-run 模式：
```
预览模式 (--dry-run)

以上记录将在实际清理时被删除
使用 `/mnemosyne:clean --days 90` 执行清理
```
