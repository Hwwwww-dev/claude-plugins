# /mnemosyne:stats - 统计信息

---

## 执行流程

1. **读取索引**：从 `index.json` 获取所有记录
2. **计算统计**：
   - 总数量
   - 按标签分布
   - 按时间分布
   - 质量评分分布
   - 存储空间占用

---

## 输出格式

```markdown
## Mnemosyne 统计

### 概览
| 指标 | 值 |
|------|------|
| **总上下文数** | 15 |
| **存储位置** | .claude/mnemosyne/ |
| **占用空间** | 2.3 MB |
| **最早记录** | 2024-12-01 |
| **最新记录** | 2024-12-25 |

### 标签分布
| 标签 | 数量 |
|------|------|
| feature | 8 |
| bugfix | 4 |
| refactor | 2 |
| config | 1 |

### 质量评分
| 评分 | 数量 |
|------|------|
| 8/8 (完整) | 10 |
| 7/8 | 3 |
| 6/8 | 2 |

### 时间分布
| 月份 | 数量 |
|------|------|
| 2024-12 | 10 |
| 2024-11 | 5 |

---

使用 `/mnemosyne:clean` 清理过期记录
```

---

## 空数据处理

```
Mnemosyne 统计

暂无保存的上下文

使用 `/mnemosyne:save` 开始保存会话上下文
```
