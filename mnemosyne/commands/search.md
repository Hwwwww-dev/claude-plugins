# /mnemosyne:search - 搜索上下文

用户输入: $ARGUMENTS

---

## 搜索维度

1. **标题搜索**: 匹配上下文标题
2. **标签搜索**: `--tag` 按标签过滤
3. **内容搜索**: 全文搜索上下文内容
4. **时间过滤**: `--from` 和 `--to` 指定时间范围

---

## 执行流程

1. **解析参数**：提取关键词和过滤条件
2. **读取索引**：从 `index.json` 获取元数据
3. **执行搜索**：
   - 先按标签过滤（如有）
   - 再按时间过滤（如有）
   - 最后按关键词匹配标题和内容
4. **排序结果**：按相关度和时间排序

---

## 输出格式

```markdown
## 搜索结果: "认证"

找到 3 个匹配的上下文：

### 1. 实现用户认证功能
- **ID**: 20241225-103000
- **标签**: feature, auth, React
- **时间**: 2024-12-25 10:30
- **匹配**: 标题、内容

### 2. 修复认证 Token 过期问题
- **ID**: 20241220-140000
- **标签**: bugfix, auth
- **时间**: 2024-12-20 14:00
- **匹配**: 标题

### 3. 认证模块重构
- **ID**: 20241215-090000
- **标签**: refactor, auth
- **时间**: 2024-12-15 09:00
- **匹配**: 内容

---

使用 `/mnemosyne:load <ID>` 加载指定上下文
```

---

## 无结果处理

```
搜索: "xxx"

未找到匹配的上下文

尝试：
- 使用更宽泛的关键词
- 移除标签过滤
- 扩大时间范围
```
