# /mnemosyne:delete - 删除上下文

用户输入: $ARGUMENTS

---

## 执行流程

1. **验证 ID**：检查指定的上下文是否存在
2. **显示详情**：展示要删除的上下文信息
3. **确认删除**：使用 AskUserQuestion 确认
4. **执行删除**：删除文件夹和更新索引

---

## 确认流程

```markdown
## 删除确认

即将删除以下上下文：

**标题**: 实现用户认证功能
**ID**: 20241225-103000
**标签**: feature, auth, React
**保存时间**: 2024-12-25 10:30

此操作不可恢复，确认删除吗？
```

**使用 AskUserQuestion**:
- 选项 1: 确认删除
- 选项 2: 取消

---

## 强制删除

使用 `--force` 参数跳过确认：
```
/mnemosyne:delete 20241225-103000 --force
```

---

## 输出格式

删除成功：
```
上下文已删除

已删除: 实现用户认证功能 (20241225-103000)
```

取消删除：
```
已取消删除操作
```

ID 不存在：
```
未找到 ID 为 "xxx" 的上下文

使用 `/mnemosyne:list` 查看所有上下文
```
